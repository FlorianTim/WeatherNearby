# LumbreCode knowledge base

- LumbreCode keeps a central software knowledge base (Google Drive folder
  `lumbrecode-product-knowledge`): what each app currently does, and which
  capabilities, libraries and standards already exist across projects.
- Before a **major** feature, suggest `/knowledge start <feature>` to check the
  app's current state and reuse opportunities. After completing one, suggest
  `/knowledge finish <feature>`. Do not suggest it for routine commits, small
  fixes or styling changes.
- Every documented app has an accurate current-state snapshot; planned work is
  never written into it.
- Reuse the app's own generated documentation and screenshots instead of
  writing or capturing new ones.
- Google Drive changes happen only at milestones and only after the user
  approves a concrete change set. Nothing synchronizes automatically.

# Implementation Plans

Implementation plans are derived from mature feature specs and describe the technical approach
before individual stories are created.

## Directory structure

One implementation plan per feature: `<NNNN-feature-name>.md`

## Template

See `_template.md` in this folder.

## Rules

- An implementation plan is NOT an implementation order.
- It serves as the basis for story decomposition.
- It contains a test and validation strategy.
- Code is only changed in stories, not in the plan.

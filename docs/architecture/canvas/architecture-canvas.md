# Architecture Canvas

## Problem

Mobile Produktentwicklung mit möglichem Backend, Doku, Mockups und agentischer Unterstützung
soll in einem Repo beherrschbar bleiben.

## Lösung in einem Satz

Ein Monorepo mit klarer Trennung zwischen ausführbaren Produkten, wiederverwendbaren Paketen,
Architekturwissen, Design-Artefakten und temporären Entwürfen.

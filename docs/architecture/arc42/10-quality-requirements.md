# 10. Qualitätsanforderungen

## Änderbarkeit

Neue Features sollen ohne Strukturumbau ergänzt werden können.

## Verständlichkeit

Neue Mitarbeitende oder Agenten sollen die Repo-Struktur schnell erfassen können.

## Reproduzierbarkeit

Builds und Checks sollen lokal und in GitHub Actions nachvollziehbar sein.

## Sicherheit

Keine Secrets im Repo; Signierung nur über sichere CI-Secrets.

# 06. Laufzeitsicht

## Beispiel: App-Start

1. App startet
2. `AppConfig` wird aus `dart-define` gelesen
3. `MaterialApp` wird aufgebaut
4. Startscreen / erstes Feature wird geladen

## Beispiel: API-Aufruf

1. Feature löst Aktion aus
2. Repository / Client ruft API auf
3. Backend verarbeitet Request
4. Antwort wird im UI dargestellt

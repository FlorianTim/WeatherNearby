# Ideas

This directory contains the Simple Idea Inbox and triage results.

## Structure

- `simple/ideas.md` — Quick raw idea inbox (Markdown-first)
- `simple/attachments/` — Attachments for ideas (images, sketches, audio references)
- `simple/processed-index.yml` — Processing status (maintained by agents)
- `triage/idea-triage.md` — Results of the last triage

## Rules

- Raw ideas are NEVER implemented directly.
- Agents may read, sort, and triage ideas.
- Processing status belongs in `processed-index.yml`, not in the raw ideas file.
- Feature candidates are moved to `docs/product/feature-candidates.md`.
- Roadmap updates go to `docs/product/roadmap.md`.

## Obsidian compatibility

All files are plain Markdown and can be edited in Obsidian.

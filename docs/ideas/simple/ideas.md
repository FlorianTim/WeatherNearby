# Simple Idea Inbox

> This file is the quick inbox for ideas — on the go, via phone, Obsidian, or dictation.
> Copilot may read and triage this file but MUST NOT treat it as an implementation order.

## Format

Ideas are added line by line under date headings.
Tags are optional and mark rough categorization.

**Tags:** `[now]`, `[next]`, `[v1]`, `[v2]`, `[v3]`, `[later]`, `[someday]`, `[ux]`, `[tech]`, `[bug]`, `[question]`, `[discard?]`

## Attachments

Images, sketches, or voice note references go to `docs/ideas/simple/attachments/`.

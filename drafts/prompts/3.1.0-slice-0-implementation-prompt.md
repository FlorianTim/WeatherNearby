## Why this prompt authorizes code and the planning prompt did not

AGENTS.md: *"Agents MAY implement code ONLY when an approved story or
explicit Copilot task issue exists."*

The planning pass produced seven stories under
`docs/delivery/stories/0000-shared-foundations/`, each with scope, acceptance
criteria and test requirements, each marked `ready`. That is the approval
boundary the rule names, so this prompt can point at them.

The next slice's prompt follows the same shape: draft its stories first, then
write the prompt that points at them.
